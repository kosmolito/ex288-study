# ex288-study

This repository contains study materials and notes for the `Red Hat Certified OpenShift Application Developer` (EX288) exam.
There are various README files in different directories, each providing specific information and instructions related to the content of that directory.

You can practice locally with OpenShift Local (CRC) or on the OpenShift Platforms. The idea is to have a self-contained repository with all the necessary resources and instructions to prepare for the EX288 exam.

I am focusing much more on the practical aspects of the exam, so you will find a lot of hands-on exercises and examples in the various directories.
